================================================================================
BUSINESS OVERVIEW & COMPANY GOAL
================================================================================

Project Name: Protein Corner
Business Type: E-Commerce Platform for Processed Foods
Company Goal: To provide customers with a trusted source for high-quality, ready-to-cook processed chicken, meat, and eggs. The platform aims to deliver the finest selection of protein products for quick, healthy meals, focusing on quality, convenience, and reliable delivery straight to customers' kitchens.

Key Value Propositions:
- Quality you can taste
- Ready-to-cook convenience
- Healthy meal solutions
- Reliable delivery service
- Wide selection of protein products (chicken, beef, eggs, fish, milk)


================================================================================
PROJECT OVERVIEW
================================================================================

This is a modern, responsive e-commerce frontend application built with Next.js, designed to sell processed protein products including chicken, beef, eggs, fish, and milk. The application features a complete shopping experience with product browsing, cart management, user authentication, payment processing, and customer service features.

================================================================================
STEP-BY-STEP CLONING INSTRUCTIONS
================================================================================

PREREQUISITES:
- Node.js (v18 or higher recommended)
- npm (comes with Node.js)
- Git (for cloning repository)
- MongoDB (local or cloud instance for database)

STEP 1: Clone the Repository
```bash
git clone [repository-url]
cd protein-corner-frontend
```

STEP 2: Install Dependencies
```bash
npm install
```
This will install all dependencies listed in package.json with exact versions.

STEP 3: Set Up Environment Variables
```bash
# Create .env file in root directory
touch .env

# Add your environment variables (example):
MONGODB_URI=mongodb://localhost:27017/protein-corner
# Add other required variables as needed
```

STEP 4: Start Development Server
```bash
npm run dev
```
The application will be available at http://localhost:3000

STEP 5: Build for Production
```bash
npm run build
npm start
```

================================================================================
TROUBLESHOOTING
================================================================================

1. Port already in use:
   - Kill process on port 3000 or use different port: npm run dev -- -p 3001

2. MongoDB connection issues:
   - Verify MONGODB_URI is correct
   - Ensure MongoDB is running
   - Check firewall/network settings

3. Build errors:
   - Clear .next directory: rm -rf .next
   - Reinstall dependencies: rm -rf node_modules && npm install
   - Check Node.js version compatibility

4. Styling issues:
   - Ensure TailwindCSS is properly configured
   - Check postcss.config.mjs
   - Verify content paths in tailwind.config.js
